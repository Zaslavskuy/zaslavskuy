## Промо «Маятник» trafficpro.online (`output/reels_pendulum_trafficpro.mp4`, 12.1 с, 30 fps)
Сцена — `scene_p7.html`: маятник с ракетой (разворот в 3D в крайних точках, пламя по скорости, шлейф и искры), нить работает как шторка текста.
Тайминг маятника 1:1 с референсом (крайняя правая точка в t=0, 1.2 с на взмах), поэтому звук взят из исходного ролика без сдвига.
Сборка: `SCENE=scene_p7.html node render_overlay.js <dir> 120 0 1459`, затем ffmpeg `tmix=frames=3:weights='1 2 1'` + выбор каждого 4-го кадра (motion blur, 30 fps) и аудио из референса.

## Что повторено из референса
- Кинетические субтитры: мелкое слово (Montserrat) + крупное ключевое (Oswald, капс), янтарный акцент (#FFB21E), перечёркивание «РЕЗУЛЬТАТОВ».
- Панч-ины камеры между фразами и медленный наезд внутри фразы (якорь — лицо).
- Переходы: круглая «диафрагма» (iris) в графику и zoom-blur обратно на лицо.
- Графика: 3D-дашборд с цифрами из шаблона (329 415,75 ₴ / 386 942,10 ₴ / 147 860,40 ₴), зелёными графиками и подсветкой, схема «маркетинг → продукт → трафик», браузер с набором текста + иконки Instagram/Google, аватар «не онлайн», полупрозрачная карточка Instagram-профиля @zaslavskuy с кликом по «Оставить заявку».
- Звук: SFX на каждое событие (CC0), музыкальная подложка с дакингом под голос, склейки выровнены по битам.

## Как пересобрать
```bash
node render_overlay.js <ovlDir> 25 0 984            # кадры графики (scene.html, renderAt(t))
python3 composite.py source.mp4 <ovlDir> video_noaudio.mp4
MUSIC_DB=-9 SFX_DB=4 python3 mix.py source.mp4 <sfxDir> music.mp3 mix.wav   # уровни RU v3 (по умолчанию MUSIC_DB=-13 SFX_DB=0)
bash mux.sh video_noaudio.mp4 mix.wav output/reels_final.mp4
```
Украинская версия — `LANG_CUT=uk` (+ `MUSIC_DB=-9 SFX_DB=4` для mix.py) и аргумент `uk` у `composite.py`.
Английская версия — те же команды с `LANG_CUT=en` перед `node`/`mix.py` и аргументом `en` у `composite.py`.
Русская версия рендерится сценами V3 (`renderRes3`, `renderChain3`, `renderSite3`, `renderNotif3`, `renderForm3`); английская — сценами по шаблону.
В `scene.html` (`?lang=en`) — свои субтитры `CARDS_EN`, тексты `TXT` и тайм-ремап анимаций `TMAP` под английскую речь.
Тайминги субтитров — массив `CARDS` в `scene.html`; камера — `CAM` в `composite.py`; звуки — `CUES` в `mix.py`.
