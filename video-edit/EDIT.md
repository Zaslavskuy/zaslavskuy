# Монтаж: «Привожу клиентов из интернета с 2016 года»

Вертикаль 1080×1920, 25 fps. Исходник 29.89 с → ролик **27.36 с** (684 кадра).
Без музыки. Стиль — светлый минимал, акцент `#c8623c`, шрифт Inter (кириллица).

## Где что крутить

| Хочу | Где |
|---|---|
| Поменять интервалы реза | `edl_spans.json` → `tools/build.sh` |
| Сдвинуть появление элемента | `cues.json` → `offset` у метки → `python3 tools/gen_cues.py` |
| Привязать к другому слову | `cues.json` → `word` (и `n`, если слово повторяется) |
| Поменять текст на панели | `project/compositions/scene-*.html` (разметка) |
| Цвета, шрифт, тени, радиусы | `project/index.html`, блок `:root` и общие классы |
| Раскладки камеры (окно, punch-in) | `project/index.html`, `FULL` / `STACK` / `PUNCH` |
| Анимацию сцены | `project/compositions/scene-*.html`, блок `<script>` |
| Громкость | `tools/master_audio.py` (`--target`, `--tp`) |

**Числа таймингов руками не править.** Они живут в блоке `CUES:BEGIN…CUES:END`
каждого файла и в `data-start`/`data-duration` слотов `index.html`;
генератор перезаписывает их из `cues.json`. Сопоставление слов идёт без
краевой пунктуации и регистра.

Правка в Studio: `cd project && npm run dev` (на своей машине; положить рядом
`input-video.mp4`, см. ниже).

## Пересборка

```bash
tools/build.sh            # рез + тайминги графики + звук
tools/build.sh preview    # … + out/preview.mp4
tools/build.sh master     # … + out/master.mp4 (--quality high)
```

Нужны `.tmp/raw.mp4` (исходник) и `.tmp/audio16k.wav`, модель whisper
`.tmp/models/ggml-large-v3-turbo.bin`. Видео и промежуточные файлы в git не
лежат (`.gitignore`); `project/input-video.mp4` собирается `build.sh`.

## Измерения

- Длительность: 29.86 с → 27.36 с, 8 кусков, 684 кадра — сходится с суммой сегментов.
- Остаток тишины: максимум **140 мс** (норма ≤ 150), пауз ≥ 150 мс — 0.
- Обратная расшифровка: связная, без повторов и обрубленных слов (`transcripts/final.srt`).
- Звук: −14.0 LUFS, истинный пик −1.76 dBTP после AAC; деноиз не делался (пол шума −80 dBFS).
- `npx hyperframes check`: 0 находок во всех пяти аудитах, контраст 9/9 WCAG AA.

## Отступления от исходной инструкции

1. **Анализ на +20.8 дБ.** Запись тихая (−34.8 LUFS); порог −30 dBFS считал речь
   тишиной. Огибающая оценивается на уровне будущего мастера (`envelope.py --gain`).
2. **Добор глухих окончаний** не перешагивает в следующий участок речи —
   иначе паузы < 250 мс не сжимаются (`audiolib.speech_mask`).
3. **`hold_out`** у S7: 0.32 с молчаливого хвоста исходника, чтобы финальный титр успели прочитать.
4. **Шрифт** Inter вместо системного: SF Pro на Linux-рендере нет, а комплектные шрифты без кириллицы.
5. **Мастер −1.5 dBTP в WAV**: AAC добавляет межсемпловые пики (−1.0 в WAV → −0.96 после AAC).

## Новые ловушки

- **whisper.cpp: DTW молча не работает с flash attention** (по умолчанию включён) —
  все `t_dtw = -1`. Нужен `-nfa` (`tools/words.py`).
- **DTW ошибается на протяжных гласных**: «Е-е-если» получило старт на 0.45 с позже.
  Для таких слов — `offset` в `cues.json`.
- **«а» перед фразой** — слово-паразит, а не вдох: периодичность 0.7, низкий ZCR.
  Отличать вдох от голоса по уровню здесь нельзя (разница 5–7 дБ) — только по периодичности.
- **`hold_out` до сжатия пауз** съедается сжатием — хвост добавлять после.
