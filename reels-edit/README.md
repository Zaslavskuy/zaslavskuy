# Монтаж Reels по референсу

Финальные видео (1080×1920, 25 fps, −14 LUFS / −2 dBTP):
- `output/reels_final_RU_v3.mp4` — **актуальная русская версия** (39.3 с): свои цифры, переработанная инфографика (карточка выручки + клиенты, цепочка «маркетинг/продукт/трафик → результат», сборка сайта в телефоне + трафик из Instagram/Google Ads, ночные заявки), в финале — форма заявки с нажатием
- `output/reels_final.mp4` — предыдущая русская версия (по шаблону, с карточкой Instagram)
- `output/reels_final_UK.mp4` — украинская версия (42.4 с): стиль RU v3, украинские тексты и цифры, чипы Facebook/Instagram/Google, карточка конверсии «Відвідувачі → Клієнти», форма заявки в финале
- `output/reels_final_EN.mp4` — английская версия (38.0 с): субтитры и вся инфографика на английском, суммы в долларах, без карточки Instagram в финале

## Ролик «Реклама без клиентов» (`output/reels_ads_results_RU.mp4`, 47 с)
Сцена — `scene_p3.html` (`SCENE=scene_p3.html node render_overlay.js …`, `composite.py … p3`, `LANG_CUT=p3 MUSIC_DB=-9 SFX_DB=4 python3 mix.py …`).
- 7.3–14.1 с: «Где теряются заявки» — креативы, предложение, настройки, посадочная страница.
- 15.7–20.2 с: рекламный кабинет (потрачено $2 400, 2 заявки, $1 200 за заявку) и батарейка «желания» до 3% (цифры иллюстративные).
- 22.2–31.2 с: результаты клиентов (данные от заказчика): Дубай 1 632 / $32,51 / 575%, Италия 3 228 / $7,20 / 961%, услуги 1 813 / $5,10 / 824%, серая ниша 2 357 / $4,83 / 1 617% (спотлайт, глитч, цензура, «СЕКРЕТНО»).
- Украинская версия: `output/reels_ads_results_UK.mp4` (48.6 с) — `SCENE=scene_p3.html LANG_CUT=uk node render_overlay.js …`, `composite.py … p3uk`, `LANG_CUT=p3uk MUSIC_DB=-9 SFX_DB=4 python3 mix.py …`.
- 35–40.6 с: «Вся связка» — Предложение → Креативы → Сайт → Instagram → Заявка; в финале форма заявки внизу кадра.

## Ролик «Портфолио» (`output/reels_portfolio_RU.mp4`, 37.3 с)
Сцена — `scene_p2.html` (рендер: `SCENE=scene_p2.html node render_overlay.js …`, камера `composite.py … p2`, звук `LANG_CUT=p2 MUSIC_DB=-9 SFX_DB=4 python3 mix.py …`).
- 4.0–14.6 с: витрина 4 сайтов (NACRE, ПІСЛЯ, OFFSET, REALE) — окна браузера с записями влетают каскадом, каждое следующее перекрывает предыдущее.
- 17.0–22.7 с: преимущества по речи — адаптив (десктоп → телефон), SEO (сайт поднимается на #1), структура (дерево страниц), формы заявок (тап).
- 24–30 с: карточки «Готов к запуску рекламы» и «Рекламная кампания» с тумблером и счётчиком заявок; в финале форма заявки.
- Украинская версия: `output/reels_portfolio_UK.mp4` (38.2 с) — `SCENE=scene_p2.html LANG_CUT=uk node render_overlay.js …`, `composite.py … p2uk`, `LANG_CUT=p2uk MUSIC_DB=-9 SFX_DB=4 python3 mix.py …`.
- Кадры записей сайтов берутся из `p2_frames/` (локальная ссылка, в git не хранится; извлекаются `ffmpeg -vf fps=25,scale=840:-1`).

## Что повторено из референса
- Кинетические субтитры: мелкое слово (Montserrat) + крупное ключевое (Oswald, капс), янтарный акцент (#FFB21E), перечёркивание «РЕЗУЛЬТАТОВ».
- Панч-ины камеры между фразами и медленный наезд внутри фразы (якорь — лицо).
- Переходы: круглая «диафрагма» (iris) в графику и zoom-blur обратно на лицо.
- Графика: 3D-дашборд с цифрами из шаблона (329 415,75 ₴ / 386 942,10 ₴ / 147 860,40 ₴), зелёными графиками и подсветкой, схема «маркетинг → продукт → трафик», браузер с набором текста + иконки Instagram/Google, аватар «не онлайн», полупрозрачная карточка Instagram-профиля @zaslavskuy с кликом по «Оставить заявку».
- Звук: SFX на каждое событие (CC0), музыкальная подложка с дакингом под голос, склейки выровнены по битам.

## Как пересобрать
```bash
node render_overlay.js <ovlDir> 25 0 984            # кадры графики (scene.html, renderAt(t))
python3 composite.py source.mp4 <ovlDir> video_noaudio.mp4
MUSIC_DB=-9 SFX_DB=4 python3 mix.py source.mp4 <sfxDir> music.mp3 mix.wav   # уровни RU v3 (по умолчанию MUSIC_DB=-13 SFX_DB=0)
bash mux.sh video_noaudio.mp4 mix.wav output/reels_final.mp4
```
Украинская версия — `LANG_CUT=uk` (+ `MUSIC_DB=-9 SFX_DB=4` для mix.py) и аргумент `uk` у `composite.py`.
Английская версия — те же команды с `LANG_CUT=en` перед `node`/`mix.py` и аргументом `en` у `composite.py`.
Русская версия рендерится сценами V3 (`renderRes3`, `renderChain3`, `renderSite3`, `renderNotif3`, `renderForm3`); английская — сценами по шаблону.
В `scene.html` (`?lang=en`) — свои субтитры `CARDS_EN`, тексты `TXT` и тайм-ремап анимаций `TMAP` под английскую речь.
Тайминги субтитров — массив `CARDS` в `scene.html`; камера — `CAM` в `composite.py`; звуки — `CUES` в `mix.py`.
